# Структура репозитория

- **`гп_иад_предобработка.ipynb`** — предобработка данных + базовый EDA
- **`GP_ML_(IAD)_EDA_FE_withoutgraphs.ipynb`** — расширенный EDA и генерация признаков
- **`gp_ml.ipynb`** — основной ноутбук с моделями и экспериментами
- **`lr_and_rf.ipynb`** — линейная регрессия + Random Forest
- **`regressions.ipynb`** — эксперименты с регрессионными моделями
- **`ModelsMetricsAnalysis.ipynb`** — анализ и сравнение метрик моделей
- **`eda_univariate_cat.ipynb`** / **`eda_univariate_numeric.ipynb`** — одномерный анализ признаков
- **`ml_utils.py`** / **`pipelines.py`** — вспомогательные модули (утилиты и пайплайны)
- **`df_fe.parquet`** — предобработанный датасет
